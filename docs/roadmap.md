# Roadmap

1. Add explicit timezone and interval-duration metadata to the input contract.
2. Add a pluggable persistence layer for larger snapshots while keeping CSV as a simple source.
3. Expose validated summaries through a read-only local API.
4. Add configurable baselines and compare anomaly signals against operator-confirmed events.
5. Package the pipeline for scheduled container execution with structured logs and health reporting.

These are proposed steps, not implemented features.
